# HSI Dashboard Feature

Folder ini berisi satu module dashboard HSI end-to-end:

- `frontend/`: tampilan login dan dashboard.
- `backend/`: session auth dan dashboard state.
- `domain/`: data seed dan logika perhitungan report.

Untuk membuat dashboard serupa, copy folder ini sebagai feature baru, lalu sesuaikan nama dashboard, label report, dan data sumber di `domain/reporting/seed-data.ts`.
